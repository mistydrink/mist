# mistydrink.github.io

My portfolio. You get to it by falling into a black hole.

**Live:** https://mistydrink.github.io

## What's in it

- A WebGL black hole made of 42,000 particles. All the motion runs on the GPU, the resolution drops automatically on slow devices, and it stops rendering once you've scrolled past it.
- A scroll intro that pulls you through the event horizon.
- A purple macOS-style desktop: a menu bar, a Dock and glass windows.
- My projects, experience, tech stack and a contact form.
- 13 space easter eggs. Press `?` on the site to track the ones you've found.

## Running it

It's one `index.html` with no build step and no dependencies. Open it in a browser, or serve the folder with any static server.
